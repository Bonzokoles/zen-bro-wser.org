## 📊 Technology Stack

```
Frontend:        React 18 + TypeScript
Desktop:         Electron
Styling:         CSS3 + Tailwind (optional)
Build:           Vite + Webpack
Testing:         Jest + Playwright
Containerization: Docker + Podman

Backend Services:
  - Browser:     Puppeteer + Playwright
  - Scraping:    Cheerio + Crawlee
  - Search:      Tavily + Bing API
  - AI:          Claude + DeepSeek + OpenRouter
  - MCP:         Model Context Protocol
  - Network:     Custom proxy, monitoring
  - Workflows:   Custom orchestration engine

Deployment:
  - Installers:  NSIS (Win), DMG (Mac), AppImage (Linux)
  - CI/CD:       GitHub Actions
  - Monitoring:  Sentry + LogRocket
  - Updates:     electron-updater
```

pip install scrapy

# Start development
npm run dev
