# System Startup Scripts

This directory contains scripts to run different parts of the ZENO_web_CORE project.

## Scripts

### `start_main_app.bat`
**_Podstawy / Basics_**

Starts the main Astro web application. The application will be available at `http://localhost:4378`.

### `start_bielik_agent.bat`
**_Dodatki / Add-ons_**

Starts the BIELIK AI agent system in development mode.

### `run_dev_tools.bat`
**_Narzędzia / Tools_**

Runs development tools, such as the code validator (`validate:working` script).
