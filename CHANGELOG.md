## [0.0.1] - 2026-03-14

### ✨ New Features
- Initial release of ZENO Browser
- Multi-tab browser UI built with Astro 5 + React 18
- AI integration: Gemini, OpenRouter (8 models), Claude support
- MCP tools: web_search, content_analysis, bookmark_manager, page_summarizer, link_extractor, web_navigation
- BIELIK Agent System: Researcher, Coder, Planner agents
- Tavily search integration
- Cloudflare Workers deployment support
- Docker Compose configuration for local development
- Version control workflow (original/working/active system)
