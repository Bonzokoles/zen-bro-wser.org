# Steps 8-10: Installers, Release Automation & Documentation

Today we're completing the foundational setup of ZENO Browser with three major additions: platform installers, automated releases, and this documentation website.

<!--truncate-->

## 🪟 Windows NSIS Installer (Step 8)

The Windows installer uses NSIS (Nullsoft Scriptable Install System) and provides:

- One-click installation with a guided wizard
- Custom install directory selection
- Desktop and Start Menu shortcuts
- Uninstaller with user data preservation
- Registry entries for URL handling

```powershell
# Build the Windows installer locally
node scripts/build-nsis.js --arch=x64
```

## 🍎 macOS DMG Installer (Step 8)

The macOS installer provides the familiar drag-and-drop experience:

- Background image with visual install instructions
- Apple Silicon (M1/M2/M3) and Intel builds
- Code signing support (when certificate is configured)
- Notarization support via `xcrun notarytool`

```bash
# Build the macOS DMG
node scripts/build-dmg.js --arch=arm64
```

## 🐧 Linux AppImage + deb + rpm (Step 8)

Linux users get multiple packaging options:

- **AppImage** — portable, no installation needed
- **.deb** — for Debian/Ubuntu/Mint
- **.rpm** — for Fedora/RHEL/openSUSE
- Desktop integration via `.desktop` file

```bash
# Build all Linux packages
node scripts/build-appimage.js --target=all
```

## 🚀 GitHub Actions Release Workflow (Step 9)

The new `release.yml` workflow automates the entire release process:

1. Builds installers for all platforms in parallel
2. Generates a changelog from conventional commits
3. Creates a GitHub Release with all assets
4. Supports both manual triggers and tag-based releases

```yaml
# Trigger a release manually from GitHub Actions
# or push a version tag:
git tag v1.0.0
git push origin v1.0.0
```

## 🔄 Auto-Updater (Step 9)

The `AutoUpdaterService` in `src-electron/services/auto-updater.ts` provides:

- Automatic background update checks (every 4 hours)
- Delta updates to minimize download size
- User notifications for available and downloaded updates
- One-click update installation
- Rollback support

## 📚 This Documentation (Step 10)
