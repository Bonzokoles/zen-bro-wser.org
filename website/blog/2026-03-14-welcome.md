# Welcome to ZENO Browser 🚀

We're excited to introduce **ZENO Browser** — an AI-powered browser with multi-model integration, built with Astro 5 + React 18.

<!--truncate-->

## What is ZENO Browser?

ZENO Browser is not just another browser. It's a browser designed for the AI age, combining standard web browsing with deep AI integration:

- **Multi-model AI chat** — Gemini, GPT-4, Claude, and 8+ OpenRouter models
- **MCP Tools** — 6 built-in tools for web search, content analysis, bookmarks, and more
- **BIELIK Agents** — autonomous agents for research, coding, and planning
- **Cloudflare integration** — secure, fast, globally distributed

## Why We Built This

Modern browsing workflows increasingly involve AI assistance. We wanted a browser where AI is a first-class citizen — not a third-party extension, but deeply integrated into every aspect of browsing.

## Current Status

ZENO Browser is currently in **beta**. Core features work, but you may encounter rough edges. We're actively improving stability, adding features, and building out the documentation.

## Steps Completed (1-10)

We're working through a 10-step implementation plan:

1-7. ✅ Core browser UI, AI integration, MCP tools, agent system, Cloudflare deployment  
8. ✅ **Installers** — NSIS (Windows), DMG (macOS), AppImage (Linux)  
9. ✅ **Release automation** — GitHub Actions CI/CD, auto-updater  
10. ✅ **Documentation** — This Docusaurus site you're reading now!
